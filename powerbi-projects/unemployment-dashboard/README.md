## 📌 Project Overview
This project presents an interactive Power BI dashboard analyzing global unemployment trends across countries and over time. The goal is to transform raw data into clear, visual insights that support data-driven understanding.

---

## 🎯 Objectives
- Visualize unemployment trends over time  
- Compare unemployment rates across countries  
- Enable interactive filtering for deeper analysis  
- Demonstrate data visualization and dashboard design skills  

---

## 🛠️ Tools & Technologies
- Power BI Desktop  
- DAX (Data Analysis Expressions)  

---

## 📂 Dataset
The dataset contains global unemployment statistics with the following fields:

- `country_name` – Name of the country  
- `country_code` – Country code  
- `year` – Year of observation  
- `unemployment_rate` – Percentage of unemployment  

---

## ⚙️ Features & Functionality

### 📈 Trend Analysis
A line chart visualizes how unemployment rates change over time.

### 🌍 Country Comparison
A bar chart compares average unemployment rates across selected countries.

### 🎯 KPI Indicators
Key metrics displayed:
- Average Unemployment  
- Maximum Unemployment  
- Minimum Unemployment  

### 🎛️ Interactive Filtering
- Country slicer enables selection of specific countries  
- All visuals update dynamically based on user selection  

---

## 📊 Dashboard Outputs
- Full dashboard view displaying all data  
- Filtered dashboard view showing selected country insights  
- Screenshots included in the repository  

---

## 🧠 Key Insights
- Unemployment rates vary significantly across countries  
- Some countries show consistently higher unemployment levels  
- Trends fluctuate over time, indicating changing economic conditions  

---


---

## 🚀 How to Use
1. Open the `.pbix` file in Power BI Desktop  
2. Use the slicer to filter by country  
3. Explore trends and comparisons through the visuals

This dashboard demonstrates the ability to transform raw data into meaningful visual insights using Power BI, focusing on clarity, interactivity, and effective data storytelling.
